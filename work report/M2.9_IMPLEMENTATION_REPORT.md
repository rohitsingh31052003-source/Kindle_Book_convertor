## Architecture

### Detection Pipeline

```
ReconstructedDocument → _analyze_headings() → _HeadingAnalysis[]
  → _classify_explicit_chapters() → explicit_indices
  → _classify_number_sequence_chapters() → number_seq_indices
  → _classify_title_only_chapters() → title_only_indices
  → _build_detected_chapter() → ChapterDetectionResult
```

### Classification Strategy (Conservative)

1. **Explicit chapters**: Headings matching `Chapter N`, `Part N`, etc. with a parsed number. Requires monotonic increasing sequence for multi-chapter detection.
2. **Number-sequence chapters**: Bare number headings (e.g., "1", "Chapter 1") forming a monotonic increasing sequence.
3. **Title-only chapters**: Headings with no keyword or number, detected by structural evidence:
   - Consistent typography (all bold, or all centered, or tight font-size variation)
   - Separated by body content (not adjacent in document order)
   - Minimum `MIN_TITLE_ONLY_HEADINGS` (2) required

### Key Data Models

- `DetectedChapter`: Frozen dataclass with `text`, `order`, `page_number`, `kind`, `reasons`
- `ChapterDetectionResult`: Frozen dataclass with `chapters`, `candidates`, `chapter_count`
- `ChapterNumberType`: Enum (`ARABIC`, `ROMAN`, `WORD`, `NONE`)

## Bugs Fixed

1. **`_is_bold_paragraph`**: Changed `"BOLD" in str(flags)` to `flags & FontFlags.BOLD` — `FontFlags` is an `IntFlag`, so `str(FontFlags.BOLD)` returns `"16"`, not `"BOLD"`.

2. **`_classify_title_only_chapters` separation check**: Changed from using enumerate index (`candidates[j][0]`) to document element index (`candidates[j][1].index`) — headings separated by body paragraphs have non-adjacent document indices even when adjacent in the analyses tuple.
