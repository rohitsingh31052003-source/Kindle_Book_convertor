## 3. Exact multi-column algorithm

`reconstruct_page_order` unchanged in signature: `<= 1` block returns
as-is; else try `_multicolumn_order(page)`, fall back to `_legacy_order`
(bit-for-bit M2.2) on `None`.

`_multicolumn_order`: (1) page text span; label full-width blocks
(fraction `>= 0.85` AND width `>= 200pt`); (2) cluster only eligible
blocks with M2.2 `_column_groups`; drop `< 2`-member clusters,
full-width-member clusters, and 2-block A-B-C chains whose ends never
overlap; (3) accept only if `2 <= n <= 4`, owned share `>= 0.5`,
pairwise x-overlap `<= 0.25 * narrower`, positive vertical overlap, edge
gutter `>= 4.0pt`; (4) `_assemble_bands`: separators above/below emit
before/after, inside separators cut each column by block-center vs
cut-center; each band emits columns left-to-right via M2.2 row grouping.

## 4. Column detection

Conservative x-overlap components on eligible blocks + evidence gates
above. Columns need `>= 2` blocks each, joint coverage `>= 50%`, mutual
vertical overlap, gutter `>= 4pt`, overlap `<= 25%` of narrower, at most
4 columns (2- and 3-column supported, count not hard-coded).

## 5. Full-width blocks

Full-width = separators, never clustered, emitted at vertical position
(before / between / after column bands): heading above reads first, note
below reads last, note between rows cuts each column at its height.

## 6. Bridge blocks

Wide bridges are excluded from clustering: columns survive, bridge reads
at its vertical position. Narrow centered objects joining one side via
overlap cannot split the page (singleton-chain guard rejects 2-block
A-B-C chains).

## 7. Mixed layouts

Per-page vertical bands (`Title / L-col / R-col / Note`); per-page scope
preserved so single-column and multi-column pages in one document each
use their own path (`PageLayout` test included).

## 8. Single-column safety

## 9. Thresholds

`ROW_OVERLAP_TOLERANCE_PT=2.0`, `ROW_TOP_TOLERANCE_PT=8.0`,
`COLUMN_OVERLAP_RATIO=0.5` (M2.2, unchanged);
`COLUMN_MIN_BLOCKS=2` (kills lone-object columns);
`COLUMN_GAP_TOLERANCE_PT=4.0` (min gutter);
`COLUMN_MAX_OVERLAP_RATIO=0.25` (max inter-column overlap);
`COLUMN_FULL_WIDTH_FRACTION=0.85` + `COLUMN_FULL_WIDTH_MIN_PT=200.0`
(full-width gates); `COLUMN_MIN_COVERAGE_FRACTION=0.5` (owned share);
`COLUMN_MAX_COUNT=4` (column cap).
